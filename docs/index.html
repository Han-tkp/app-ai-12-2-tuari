Built for Precision

Everything you need for professional spray droplet analysis in one application.

AI Detection

Real-time YOLO-based droplet detection with ByteTrack multi-object tracking at 30 FPS. Supports 4x and 10x objective lenses with calibrated ONNX models.

WHO Standards

Volume-weighted statistics calculated per WHO specifications: Dv0.1, Dv0.5 (VMD), Dv0.9, and SPAN. Spread-factor correction applied by droplet size range.

Multi-Slide Workflow

Organize analysis data across three or more slides with per-slide filtering. Track droplets by slide, compare results, and manage sessions efficiently.

Export and Reports

Generate comprehensive Excel reports with full droplet data. Save and reload sessions as .drop project files for seamless collaboration.
